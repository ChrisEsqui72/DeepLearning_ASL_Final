# DeepLearning_ASL_Final

# Description
The ASL Fingerspelling Recognition System will take in ASL fingersigns and turn that into speech to communicate. It bridges the gap between deaf and blind communication as well as deaf and regular hearing individuals. We intend to implement this by using 
the Kaggle ASL dataset to train a CNN that can interpret ASL images. The images will be ASL characters 0-9 and A-Z. The string will then be placed into a text to speech model that will hopefully be able to curb errors from the ASL model. 

# Motivation
The motivation behind this project is to help deaf individuals who use ASL to communicate. This project will enable them to communicate with anyone who doesn’t know ASL or individuals who may be blind and cannot communicate that way. This project could have 
real world implications because this could be a system that has a daily use case. It is directly helping a disadvantaged group overcome daily struggles they have. The basic implementation at the end of this class could be fully expanded into a legitimate 
software. If it isn’t directly used, insights from the development process could be used by someone who is trying to build a model and system that replicates the same ideals. 

# Dataset
The dataset that we will be using is the American Sign Language Dataset by Ayush Thakur on Kaggle. The dataset is made up of images of hands making ASL letters A-Z and 0-9 and their corresponding label of such. The dataset is also open source. After a 
preliminary look at the dataset it looks as though the images are of good quality and will not need much preprocessing.
